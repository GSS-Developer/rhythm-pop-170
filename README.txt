もう一回！ RHYTHM POP 170 — Android/iPhone共通PWA

このフォルダの全ファイルを同じHTTPSサイトにアップロードしてください。ZIPをスマホで開くだけではアプリとしてインストールできません。

Android: Chromeで公開URLを開く → メニュー → アプリをインストール／ホーム画面に追加。
iPhone: Safariで公開URLを開く → 共有 → ホーム画面に追加 → 追加。

ゲームは横画面向けです。iPhoneでは端末の画面回転ロックを解除して横向きにしてください。
初回の読み込みにはネット接続が必要です。読み込み後はオフライン利用を想定しています。
